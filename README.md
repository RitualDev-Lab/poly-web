# Poly Web — Enterprise Platform & Documentation

[![CI](https://github.com/RitualDev-Lab/poly-web/actions/workflows/ci.yml/badge.svg)](https://github.com/RitualDev-Lab/poly-web/actions)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Powered by Poly](https://img.shields.io/badge/Orchestrated%20by-Poly-38bdf8.svg)](https://github.com/RitualDev-Lab/poly)

The official flagship enterprise web platform, interactive terminal simulator, ROI calculator, and documentation portal for **[Poly](https://github.com/RitualDev-Lab/poly)** — The Universal Polyglot CLI Package & Dependency Orchestrator for Node.js, Python, Rust, and Go.

Live portal: **[https://poly.ritualdev.in](https://poly.ritualdev.in)**

---

## Features

- **Interactive CLI Simulator**: In-browser runnable terminal previewing `poly add`, `poly doctor`, `poly fix`, `poly docker`, `poly cache`, and `poly mcp`.
- **Under-the-Hood Architecture Explorer**: Visual walkthrough of PURL resolution, composite cryptographic `poly.lock`, and native execution engines.
- **Enterprise Monorepo ROI Calculator**: Interactive sliders computing monthly engineering hours regained, cloud CI spend saved, and net ROI multiplier.
- **Enterprise Pricing & Packaging Matrix**: Full comparison of Community (Open Source $0), Team ($29/mo), and Enterprise ($99/mo / Air-gapped on-prem) tiers.
- **Interactive Documentation Browser**: Built-in Quickstart, CLI Reference, `poly.toml` Schema, GitHub Actions guide, and AI Coding Agent (MCP) setup.
- **Enterprise Pilot Scheduler**: Direct intake form for 30-day proof-of-concept enterprise trials.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run Biome linter and formatter
npm run check

# Build production bundle
npm run build
```
